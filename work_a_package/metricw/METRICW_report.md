## 1. 표본가중 수식과 그룹별 실제 가중 통계

### 1-1. 수식

$$w_i=\mathbb 1\!\left(y_i\ge 0.10\,C\right)\cdot\left(\frac{0.5}{n_{\text{eval}}}+\frac{0.5\,y_i}{\sum_{j\in\text{eval}} y_j}\right)$$

- 앞항 = NMAE 몫 (마스크 내 균등) · 뒷항 = FICR 몫 (발전량 비례) · 마스크 밖 = 가중 0
- **구현상 정규화**: 원수식의 가중 합은 1.0 (~1e-4 절대 스케일)인데, 이 스케일은
  lightgbm에서 subsample bagging 시 수치 손상을 유발(스모크에서 W2 TOTAL −0.07 붕괴 확인).
  **가중은 상대 비율만 의미**하므로 합=n으로 정규화 (상대 비율 2.6:1 보존, 수식적 동일).

### 1-2. 가중 통계 (seed42, 학습 2022-23 기준)

| G1 | 17,419 | **62.7%** | 1.000 | 2.416 | 6,782 | 10,479 |

## 4. 결정성

- 문제: 초기 구현에서 LGB(MSE)가 **비균등 가중치에서 병렬 합산 잡음**(2회 max diff ~7e-12)으로
  md5 불일치 (W0는 균등 가중이라 결정적이었음 — 원인 격리로 확인).
- 해결: `LGB_M`에 `deterministic=True` 추가 (lightgbm 4.x 지원, 병렬 유지·시간 동일).
- **검증**: W2 seed42 동일 커맨드 2회 실행 → md5 `6f1e43f3ba975d340319300450b38d1c` 완전 일치.
- XGB/CatBoost/LGB-L1은 처음부터 결정적이었음 (2회 max diff 0.0).

## 6. 2차 평가 소명 문장 (지시서 §4 원문 포함)

> 대회 평가식은 `actual ≥ 0.10 × capacity` 인 행에서만 계산되며, FICR은 실측
> 발전량으로 가중된다. 그러나 표준 회귀 학습은 전체 분포(마스크 밖 39~46% 포함)의
> 조건부 중앙값을 추정하므로, 점수가 부여되는 부분집합 위에서 체계적 하향편향
> (마스크 기준 −0.18~0.21 cap, FICR 가중 기준 −0.32~0.36 cap)을 갖는다.
> 본 연구는 학습 표본가중을 평가식과 동일한 형태
> $w_i=\mathbb 1(y_i\ge0.1C)\,(0.5/n+0.5\,y_i/\sum y)$ 로 정합시켜 이 편향을 제거했다.
> 이 교정에는 연도 적합 상수가 포함되지 않으므로 연도전이 위험이 구조적으로 낮다.

**실측 뒷받침**: 연도전이 홀드아웃(2022-23→2024)에서 W2가 W0 대비 ΔTOTAL +0.01768 (3/3 양수),
널대조 +0.02122 초과. 8연속 실패(2023/24 적합 상수 이동)와 달리 **연도 적합 상수 0개** —
목적함수 구조 변경만으로 달성. 유일한 전이 성공 레버(CNN 편입)와 동일한 "순수 구조 변경" 패턴.
